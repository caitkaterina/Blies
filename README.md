# BLIES

Next.js App Router, React and TypeScript foundation for the BLIES website.

## Development

Use Node.js 24 and run `npm ci`, then `npm run dev`.

Validation: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.

The original website brief must be restored before final content, factual claims, launch scope and roadmap can be approved. No operational credentials, certifications, fleet ownership or service coverage are asserted by this foundation.
